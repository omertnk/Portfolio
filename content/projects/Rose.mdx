## Overview

An Ability System was used for the core gameplay, designed in a modular fashion. On the animation side, 
an animation layer system was implemented; this allows for easy adjustments—such as modifying only the cycle animations if the character sustains a leg injury—without the need to rebuild the entire state machine.


## What I built

- Flash-bang mechanic built on the Ability System (allows us to briefly blind enemy soldiers and escape)
- Enemy AI – Chase, investigate, and capture systems based on behavior trees
- Animation Layer – Enemy and character animation systems were coded once, turning the process into a purely asset-based task
- Push/Pull objects – The character can push boxes to reach specific locations or solve puzzles
- Various puzzle mechanics – The character must solve puzzles within the level to exit certain areas

## Challenges & learnings

This was my first project, and through it, I was introduced to the Unreal Engine architecture. It taught me how not to write good code and what happens when you fail to prioritize optimization—even for a simple game.
